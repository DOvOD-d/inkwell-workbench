# Inkwell Workbench · 墨池工作台

一个本机优先的 Word 模板工作台：把任意 `.docx` 变成可反复填写的模板，识别填写位、
读取模板自己写明的格式要求并照做，最后生成一份干净的 Word。

界面用 PySide6 写成，Windows 桌面运行；文档解析全部在本地完成，只有你主动配置并触发
AI 功能时才会联网。

## 功能

- **无占位符识别**：直接读 OOXML 的表格、合并单元格、下划线、括号提示、内容控件与表单域。
- **结构 + 文本模型**：把文档结构清单交给文本模型判断栏目名/分组/单行多行；模型给的坐标
  必须能在原文对上，否则丢弃。
- **模板要求照做**：读取文档里写明的字体、字号、行距、缩进、空行与内容要求，生成时套到
  填写内容；普通黑字写的格式要求也会识别（只套格式、不删原文）。
- **文本框说明**：浮动文本框里的填写说明先读取并挂到对应栏目，再删除文本框；
  新版 `wps:txbx` 与旧式 VML 文本框，无论哪种模板，生成/导入后的文件里都不保留。
- **突出显示清理**：生成/导入时删除所有 `w:highlight`，文字与底纹不动。
- **排版工作台**：整篇文档按纸张/字体/行距/标题规则重排，整页预览、撤销重做、导出。
- **实用小功能**：批量按名单生成、结构体检、OOXML 自检、文献检索页、玻璃质感界面。
- **超页提醒**：实时预览记录模板原本页数，输入内容把文档撑到下一页时右下角提醒。

## 目录

```
*.py                应用源码（入口 main.py）
assets/             内置模板、图标与库预览图
skill/              word-template-filler 技能包
Word模板工作台.spec  PyInstaller 打包配置
release/            打包好的 exe、技能包、示例、许可与说明
```

## 发布内容（v1.0.5）

`release/` 收录最新精简交付包中可入库的部分：

- `Word模板工作台_v1.0.5.exe`：单文件主程序。
- `使用说明-先看这里.txt`：版本变更与使用提示。
- `word-template-filler.skill`：可直接安装到 Qoder 的技能包。
- `示例/`：3 份演示模板。
- `AI_LICENSE_*.txt`：随程序分发的第三方组件许可。
- `SHA256SUMS.txt`：发布文件校验和。

识别按 OOXML 的真实表格网格工作：空单元格、占位符和彩色示例才作为填写位，标签格不会被误当成值；复杂合并表、已填基本信息、内容控件都做了跨文档测试（v1.0.5）。

`ai_models/` 与 `ai_runtime/` 不入库：内置模型约 378 MB，超过 GitHub 单文件 100 MB 限制。
需要离线 AI 时，把 Qwen3-0.6B 的 `.gguf` 放进 `ai_models/`、llama.cpp 运行库放进 `ai_runtime/`，
与 exe 同级即可；也可以直接使用 Ollama 或在线模型。

## 运行与构建

```bat
python -m venv .venv
.venv\Scripts\pip install -r requirements.txt
.venv\Scripts\python main.py
```

打包：

```bat
.venv\Scripts\pip install pyinstaller
.venv\Scripts\python -m PyInstaller --noconfirm --clean Word模板工作台.spec
```

## 隐私

- 识别、填写、排版、生成默认都在本机完成。
- 配置了在线或本机模型时，只有你点“识别/生成”等按钮才会调用；API Key 只保存在本机数据目录。
- 仓库里的内置模板已脱敏，学校名替换为“××××学院”。

## 说明

- 内置模板来自公开的科研项目表格样式，仅作演示。
- 依赖 Windows 上的 Word/WPS 才能做整页预览与 PDF 导出；没有时仍可识别与生成。
